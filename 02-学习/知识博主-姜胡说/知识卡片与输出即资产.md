# 🃏 知识卡片与"输出即资产"

## 概念

**阅读不是下载，是安装。**

划线、摘抄、收藏、听课，只是把别人的知识搬到了你的硬盘上——那叫**下载**。
只有当它改变了你的一个决策、一个行为、一个结果，才算**安装（运行）**。

而承载"运行"的最小单元，是**知识卡片**。

## 为什么

作者给了一个估计：**70% 的人学习只停留在下载，从来没运行过。**

一个反例对照：
- A 一年读 50 本书，划线、做笔记，读完就忘
- B 一年只读 5 本，但每本都拆透、连接自己的生活、结晶成卡片

五年后，B 比 A 强十倍。差的不是阅读量，是**有没有把知识变成资产**。

## 怎么用

### 一、知识卡片五要素

卡片**不是摘抄**。摘抄是死的，卡片是活的。一张标准卡片包含：

| 要素 | 回答的问题 |
|---|---|
| **概念** | 这是什么？一句话说清楚 |
| **为什么** | 背后逻辑是什么？为什么重要？ |
| **怎么用** | 在我的生活里怎么应用？列具体行动 |
| **案例** | 我自己的经历，或我看到的真实案例 |
| **边界** | 什么情况下不适用？ |

> 本知识库的新笔记已统一采用这个结构，见 [[骨架与变量]]。

### 二、"烟花还是资产"自检

很多人拍完一条内容就过去了，下次从零开始——这叫**烟花**：放的时候好看，放完什么都没剩。

替代做法：每条内容结束后**提取核心，做成卡片**并入库。

自检三问：
1. 这是不是资产？
2. 三年后还有没有用？
3. 我愿不愿意把它留下来？

三个都是"是"，才值得做。

作者给的比喻：多数人做内容是**打猎**（今天兔子、明天鹿，天天碰运气）；他做的是**种庄稼**（播种浇水施肥，看着慢，但地是自己的，年年有收成）。

### 三、写文章 = 最低成本的创业

创业要什么？发现需求 → 做出产品 → 交付 → 收钱 → 迭代。
**一篇文章全干了**：发现读者的问题（需求）、写出解决方案（产品）、发出去（交付）、有人付费（收钱）、反馈来了改版（迭代）。

作者的做法是给文章**带版本号**（v1、v2、v3），像软件一样迭代。

### 四、最快学会一个技能：抄 → 操 → 超

- **抄**：先抄高手
- **操**：上手操练
- **超**：练熟才谈超越

很多人一上来就想"超"，觉得"抄"丢人。但不会抄的人，连站在谁肩膀上都不知道。

**关键区分**：抄**骨架**，不是抄变量。
- 把人家的结构拆出来，换上自己的案例和语言 → **学习**
- 把人家的开头、例子、金句原样搬过来 → **抄袭**

案例：富兰克林练写作——找好文章读几遍，合上书用自己的话重写，再与原作对比找差距，反复循环。

## 边界

- **不是所有领域都适合"先粗糙"** —— 作者自己指出：医疗、金融风控等要精确、要安全的领域，不能粗糙开始。
- 卡片积累到几千张后，**检索与组合成为新瓶颈**；没有好的索引/链接结构，卡片库会退化成"另一种收藏夹"。
- "输出即资产"假设了输出会被消费；无人消费的输出只是自娱，不构成资产。
