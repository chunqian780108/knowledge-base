知识库 GitHub 同步 · Windows 配置指南

从零开始，在 Windows 电脑上通过 GitHub 同步你的 Obsidian 知识库

github.com/chunqian780108/knowledge-base
0
前置准备
  • GitHub 账号：已有，用户名 chunqian780108
  • 另一台 Mac 已推送最新内容：在 Mac 上的 Obsidian 里点 Git 插件的 Push，或运行 bash push-to-github.sh
  • 本指南涉及的文件：clone 仓库后会自动获取 push-to-github.ps1 脚本
1
安装 Git for Windows

打开浏览器，访问 https://git-scm.com/download/win，下载并安装。安装时关键选项如下：

  • 选择 Git from the command line and also from 3rd-party software（默认选项）
  • 凭据助手选 Git Credential Manager（默认选项，首次 push 会弹出登录窗）
  • 其余选项保持默认即可

安装完成后，打开 PowerShell（开始菜单搜索 PowerShell），验证安装：

git --version # 应输出类似：git version 2.43.0.windows.1
如果显示版本号，说明安装成功。如果提示"不是内部或外部命令"，重启电脑后再试。
2
创建 GitHub Personal Access Token (PAT)

Git 推送需要密码，但 GitHub 已不支持用账号密码认证，需要生成一个 Token 作为密码。

  1. 浏览器打开 https://github.com/settings/tokens
  2. 点击 "Generate new token" → "Generate new token (classic)"
  3. Note 填 knowledge-base-sync（随便写，方便认）
  4. Expiration 选 "No expiration"（或 90 天）
  5. 勾选 "repo"（完整仓库读写权限）
  6. 拉到底点 "Generate token"
  7. 立刻复制生成的 token（形如 ghp_xxxxxxxxxxxx），页面关掉就看不到了
Token 只显示一次，务必先复制保存到安全的地方（如密码管理器）。它是你的 GitHub 密码。
3
克隆知识库到本地

在 PowerShell 中执行以下命令（把 你的用户名 换成 Windows 登录名）：

cd $HOME\Documents git clone https://github.com/chunqian780108/knowledge-base.git KnowledgeBase

首次执行会弹出 GitHub 登录窗口：

  • 选择 "Token" 或 "Personal Access Token"
  • 粘贴刚才复制的 PAT
  • 点 登录/确认
之后 Windows 凭据管理器会自动记住凭证，不再重复输入。

验证克隆成功：

cd KnowledgeBase dir # 应看到 .obsidian、push-to-github.ps1 等文件 git log --oneline -3 # 应看到最近的提交记录

知识库本地路径为：$HOME\Documents\KnowledgeBase（即 C:\Users\你的用户名\Documents\KnowledgeBase）

4
安装 Obsidian 并打开知识库
  1. 访问 https://obsidian.md，下载 Windows 版安装包
  2. 安装并打开 Obsidian
  3. 点 "Open folder as vault"（打开文件夹作为库）
  4. 选择刚才克隆的 KnowledgeBase 文件夹
  5. 信任作者 → 确认打开
此时你的笔记、文件夹结构、Obsidian 设置都会从 GitHub 同步过来，和 Mac 上一致。
5
安装 Obsidian Git 插件（自动同步）
  1. Obsidian 设置 → 第三方插件（Community plugins）
  2. 关闭"安全模式"（Turn on community plugins）
  3. 搜索 "Obsidian Git"，安装并启用
  4. 进入插件设置，推荐配置：
    • Auto pull interval：30 分钟（定期拉取远程更新）
    • Auto push interval：30 分钟（定期推送本地变更）
    • Auto backup interval：10 分钟（定期自动提交）
    • Commit message：chore: auto backup {{date}}
插件已随仓库 clone 下来（.obsidian/plugins/obsidian-git/），启用后配置自动同步。
6
日常同步工作流

配置完成后，日常使用只需记住一个节奏：

开始编辑前 Pull
→
正常写笔记
→
自动 Commit
→
自动 Push

手动同步（如果想立即推/拉）：

  • Obsidian 里按 Ctrl+P → 输入 "Obsidian Git: Pull" 或 "Push"
  • 或在 KnowledgeBase 文件夹里右键 push-to-github.ps1 → "使用 PowerShell 运行"
两台电脑同时编辑同一文件时，可能产生冲突。建议一台电脑编辑完先 Push，另一台开始前先 Pull。
7
故障排除

推送失败 / 凭证错误

# 清除已存的错误凭证，重新输入 cmdkey /delete:git:https://github.com # 然后重新 git push，会弹出登录窗口

中文文件名乱码

git config --global core.quotepath false

拉取时冲突

# 如果 pull 报冲突，保留本地版本： git stash git pull git stash pop # 或在 Obsidian Git 设置里把 Merge strategy 改为 "Merge"

PowerShell 脚本无法运行

# 以管理员身份打开 PowerShell，执行一次： Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
